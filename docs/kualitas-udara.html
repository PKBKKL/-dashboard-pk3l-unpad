Peta Titik Sampling Udara

Warna titik = status kepatuhan parameter udara ambien yang punya baku mutu di LHU. Klik titik untuk detail.

Matriks Hasil Uji per Parameter & Titik

Warna sel = kepatuhan terhadap baku mutu di LHU. Sel abu-abu = parameter tanpa baku mutu di LHU, sehingga tidak dinilai.

Perbandingan Konsentrasi Antar Titik

Pilih parameter. Tiap batang = satu titik sampling. Garis putus-putus merah = baku mutu (bila dicantumkan di LHU).

Rincian Laporan Hasil Uji
